# AI Usage

AI is **not banned** in this repository, but it is held to one standard: you are responsible for every line you submit, and you must be able to explain it.

| | |
| --- | --- |
| **Discouraged** | AI-generated code. Prefer writing it yourself — this is a learning project as much as a language. |
| **Fine** | Planning, documentation, roadmaps, reviewing your own code, explaining unfamiliar C or compiler concepts. |
| **Rejected outright** | Code you don't understand, plausible-looking output you haven't tested, or a patch you can't defend in review. |

If AI wrote a meaningful part of a change, say so in the pull request. Nobody is penalised for disclosing it; undisclosed slop wastes a reviewer's time and will be closed.

The maintainer uses AI for parts of the documentation and the roadmap. [DESIGN.md](DESIGN.md) and [ROADMAP.md](ROADMAP.md) were written with AI assistance and reviewed by hand.
